# DayMatch 프로젝트 비전

## 미션
> 누구나 원할 때 일하고, 필요할 때 사람을 구할 수 있는 세상을 만든다.

## 비전
단기 알바 시장의 비효율을 해소하여, 구인자와 구직자 모두에게 가치를 제공하는 플랫폼이 된다.

---

## 핵심 가치 (Core Values)

### 1. 즉시성 (Immediacy)
- 일자리 등록부터 매칭까지 **1시간 이내**
- 당일 또는 익일 근무 가능
- 실시간 알림으로 놓치지 않는 기회

### 2. 신뢰성 (Trust)
- 본인인증으로 검증된 사용자
- 양방향 리뷰 시스템으로 평판 관리
- 에스크로 결제로 안전한 거래

### 3. 간편성 (Simplicity)
- 3분 내 일자리 등록
- 원터치 지원
- 복잡한 절차 없는 정산

---

## 타겟 시장

### Primary Market
| 구분 | 대상 | 페인 포인트 |
|------|------|-------------|
| 구인자 | 식당, 카페, 편의점, 이벤트 업체 | 급하게 사람이 필요할 때 구하기 어려움 |
| 구직자 | 대학생, 프리랜서, 주부 | 빈 시간 활용한 부수입 필요 |

### Secondary Market
- 물류 창고 (시즌별 인력 수요)
- 건설 현장 (일용직)
- 농촌 (수확철 인력)

---

## 차별화 포인트

### vs. 기존 알바 플랫폼 (알바몬, 알바천국)
| 항목 | 기존 | DayMatch |
|------|------|----------|
| 매칭 속도 | 지원 후 연락 대기 | 실시간 자동 매칭 |
| 근무 유형 | 장기 위주 | 단기/일용직 특화 |
| 결제 | 현금 직접 지급 | 앱 내 안전 결제 |
| 소통 | 전화/문자 | 인앱 채팅 |

### vs. 긱이코노미 플랫폼 (배달, 대리)
| 항목 | 배달/대리 | DayMatch |
|------|-----------|----------|
| 직종 | 특정 업종만 | 다양한 업종 |
| 수입 | 건당 | 시간당 급여 |
| 관계 | 플랫폼-개인 | 구인자-구직자 직접 |

## 성장 전략

### Phase 1: MVP (현재)
- 핵심 기능 구현 완료
- 특정 지역(서울) 파일럿 운영
- 사용자 피드백 수집

### Phase 2: 확장
- 수도권 → 전국 확장
- 업종별 특화 기능
- B2B 기업 고객 유치

### Phase 3: 플랫폼화
- 구직자 스킬 인증 시스템
- 보험/세금 처리 통합
- 해외 진출 (동남아)

## 팀 원칙

1. **사용자 중심**: 모든 의사결정은 사용자 가치 기준
2. **빠른 실행**: 완벽보다 빠른 출시, 빠른 개선
3. **데이터 기반**: 가설 → 실험 → 검증 사이클
4. **투명한 소통**: 문제는 숨기지 않고 공유

## 목표 NOT (명시적으로 하지 않을 것)

범위 확장(Scope Creep)을 방지하기 위해 **의도적으로 포함하지 않는** 기능들:

### MVP에서 제외
- [ ] 장기 고용 계약 지원
- [ ] 이력서/포트폴리오 관리
- [ ] 교육/자격증 시스템
- [ ] 소셜 네트워크 기능 (피드, 팔로우)
- [ ] AI 매칭 추천 (Phase 2로 연기)

### 영구 제외
- [ ] 배달/대리운전 등 특수 업종 (기존 플랫폼과 경쟁 회피)
- [ ] 국제 송금/환전 (복잡성 증가)
- [ ] 자체 보험 상품 (파트너십으로 대체)

### 기술적 제외
- [ ] 자체 결제 시스템 구축 (토스페이먼츠 사용)
- [ ] 자체 인증 서버 (Firebase Auth 사용)
- [ ] 온프레미스 배포 (클라우드 전용)
